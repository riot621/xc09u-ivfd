# マイ家計・資産アプリ (PWA)

マネーフォワード代替の簡易家計簿 + 資産管理アプリ。スマホとタブレットの両方でブラウザから利用できます。

## ファイル構成

```
index.html       … 本体 (1ファイルで完結)
manifest.json    … PWA マニフェスト (ホーム画面に追加するため)
sw.js            … サービスワーカー (オフライン対応)
README.md        … このファイル
```

## 起動方法

### 方法 A: 一番簡単 — ローカルで開く

`index.html` をダブルクリックでもほぼ動きます。ただし PWA としてホーム画面に追加するには、HTTPS または `localhost` で配信する必要があります。

### 方法 B: スマホ・タブレットで使う (推奨)

無料で使える静的ホスティングサービスにアップロードすると、URL からアクセスでき、ホーム画面に追加すればアプリのように使えます。

1. **GitHub Pages** が一番簡単です
   1. GitHub に新しいリポジトリを作成 (例: `my-kakeibo`)
   2. `index.html` `manifest.json` `sw.js` の 3 ファイルをアップロード
   3. リポジトリの Settings → Pages → Source を `main` ブランチに設定
   4. 数分後、`https://<ユーザ名>.github.io/my-kakeibo/` でアクセス可能
2. スマホで上記 URL を開く
3. iOS: Safari で「共有」→「ホーム画面に追加」
4. Android: Chrome で「ホーム画面に追加」

その他、Netlify や Vercel、Cloudflare Pages なども無料で使えます。

### 方法 C: ローカルで HTTPS 風に動かす

```bash
# Python が入っていれば:
cd この/フォルダ
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 機能一覧

### 📊 ダッシュボードタブ

* 総資産・今月の収支 KPI
* 12ヶ月の資産推移グラフ
* 今月の支出/収入の円グラフ (クリックで内訳ドリルダウン)

### 📝 家計簿タブ

* 取引の追加・編集・削除 (右下の `＋` ボタン)
* 月選択でその月の取引を表示
* レシート写真の添付 (自動圧縮で最大幅 800px)
* 定期収支の「反映待ち」を一括反映

### 💼 資産管理タブ

* **銀行口座**: 銀行名と残高を手動登録
* **株式**: 銘柄コード/ティッカーと保有数を入れると、Yahoo Finance API から株価を自動取得
  * 日本株は `7203` のように 4 桁コード
  * 米国株は `AAPL` のようなティッカー
  * 米国株は USD/JPY レートを取得して円換算
  * 取得失敗時は手動で価格入力可能
* **投資信託**: 手動入力 + CSV 取り込み
  * SBI / 楽天 / マネックスの CSV から「銘柄名」「評価額」「口数」列を自動検出
  * 形式が違う場合は `銘柄名,口数,評価額` の単純 CSV でも OK

### ⚙️ 設定タブ

* **定期収支**: 給料 (例: 毎月25日 30万円) を登録 → 家計簿タブから1クリックで反映
* **カテゴリ管理**: 収入/支出カテゴリの追加・削除
* **月末スナップショット**: 現在の総資産を月別に記録 (これがないと推移グラフが描けないので、月末に1回押す)
* **🔒 セキュリティ (パスワード保護)**: パスワードを設定するとデータがAES-256で暗号化されてブラウザに保存され、起動時にパスワード入力が必要になる。**パスワードを忘れるとデータ復旧不可**なので注意。
* **データ管理**: JSON エクスポート/インポート (バックアップ・端末間移行用)

## パスワード保護について

「設定タブ → セキュリティ → パスワードを設定」でロックを有効にできます。

* 暗号化方式: PBKDF2 (15万回イテレーション) + AES-GCM 256bit
* パスワードはアプリのメモリ上のみに保持され、ブラウザに永続化されません
* 暗号化データだけがlocalStorageに保存されるため、開発者ツールで覗いても平文は見えません
* 端末紛失・ブラウザのデータ流出時の保険として有効です
* ⚠ パスワードを忘れた場合は復旧不可。「設定 → 全データ削除」してやり直し

## 重要: データ保存について

* データは**ブラウザの localStorage** に保存されます
* **ブラウザの履歴データを消すと全データが消えます** ので、定期的に「設定 → JSONエクスポート」でバックアップを取ってください
* 別端末への移行は JSON エクスポート → 別端末でインポート で行います

## 株価取得が失敗するとき

ブラウザから直接 Yahoo Finance を叩けないため、無料の CORS プロキシ (allorigins.win, corsproxy.io) を経由しています。これらが落ちている時間帯は取得失敗します。

* 「資産管理 → 株式 → 株価を更新」で再試行
* それでもダメなときは個別に編集 → 「現在株価」欄に手入力

## 拡張: クラウド同期 (Firebase) を後で追加するには

`index.html` 内の `store` オブジェクト (`STORAGE_KEY` のすぐ下) を Firebase Firestore 版に差し替えるだけで OK な構造にしてあります。

おおまかな手順:

1. Firebase プロジェクト作成 → Firestore を有効化
2. Authentication で Google ログインを有効化
3. `<script type="module">` で Firebase SDK をインポート
4. `store.load()` を `getDoc` に、`store.save()` を `setDoc(doc(db, 'users', uid))` に置き換え
5. ログイン UI を追加

無料枠 (Firestore: 1GB / 月50K read) で個人利用なら十分間に合います。
